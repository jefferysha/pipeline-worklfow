# Find Skills

Inspect this plugin's `templates/skill-sources.yaml` and `skills/` directory first. Match the task
to an installed first-party skill and explain why it applies. Do not add an external marketplace or
download a third-party skill as a hidden prerequisite; surface a real capability gap for a user
decision instead.
