# Finishing a Development Branch

Confirm all build and verification evidence before release. Then inspect the staged diff, ensure
documentation and generated assets are current, and present any merge/rebase/squash choice that
requires a user decision. Do not push, create a PR, or delete a branch without the authority the
user granted for the current task.
