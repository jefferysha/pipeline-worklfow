# Shadcn UI

Use component primitives only where they fit the product interaction. Preserve semantic HTML,
keyboard support, focus visibility, responsive layout, and explicit empty/loading/error states.
Avoid copying a component catalogue wholesale; document any dependency and test the resulting
interaction branches.
