# Design Taste Frontend

Review the running UI for generic patterns, weak hierarchy, noisy decoration, inconsistent spacing,
and unclear interaction states. Prefer a coherent visual system and purposeful content over visual
novelty. List concrete fixes, apply them, then perform a second review; a review-only pass is not
complete.
