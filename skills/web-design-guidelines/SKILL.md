# Web Design Guidelines

Use semantic controls, visible focus, sufficient contrast, responsive layout, predictable error
recovery, and clear labels. Validate the primary flow at desktop and narrow widths. Treat visual
review as executable work: inspect the rendered interface and attach screenshots or test evidence
when the change is visual.
