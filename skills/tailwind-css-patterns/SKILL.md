# Tailwind CSS Patterns

Use a small, coherent token vocabulary and responsive breakpoints. Keep repeated component styles
in named abstractions when utilities become unreadable. Validate contrast, focus states, content
overflow, and narrow-width behavior rather than relying on desktop screenshots alone.
