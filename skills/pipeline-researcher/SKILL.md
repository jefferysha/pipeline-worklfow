# Pipeline Researcher

Define the research question, search project evidence first, then consult authoritative external
sources when needed. Separate facts, assumptions, and recommendations. Cite the exact sources,
compare alternatives against the active change's constraints, and write findings to the exploration
document for the main pipeline skill to consume.
