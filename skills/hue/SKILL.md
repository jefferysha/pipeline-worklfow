# Hue

Turn a confirmed product intent into a restrained visual language: typography scale, spacing,
color roles, surfaces, borders, motion, and interaction states. Explain the rationale and record
tokens in the design artifact. Do not select a generic dark-card layout by default or overwrite an
existing approved design system.
