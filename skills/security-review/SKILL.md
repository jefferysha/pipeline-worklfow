# Security Review

Map trust boundaries, authentication and authorization checks, untrusted input, secrets, data
exposure, logging, and dependency changes. Test the highest-risk negative paths. Record findings,
severity, and mitigation or accepted risk; never silently weaken security checks to pass tests.
