# Browser QA

Exercise the real application through the browser or the closest available runtime. Cover the
primary path, invalid input, empty/loading/error states, and at least one regression-prone branch.
Record exact steps, observed behavior, environment, and screenshots/logs where useful. Report a
blocked browser environment honestly rather than marking an unrun flow as passed.
