# Huashu Design

Before building a product prototype, ask for the desired visual direction, number of alternatives,
and reference constraints. Produce intentionally different high-fidelity variants that cover the
key journey and major states. Present runnable variants for review, wait for the user to select a
direction, then refine only the selected direction with accessibility and interaction evidence.
