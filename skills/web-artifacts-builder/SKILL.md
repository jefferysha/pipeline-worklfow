# Web Artifacts Builder

Build a navigable artifact around a documented user journey. Keep data fixtures isolated, include
empty/loading/error/success states, and make every variant directly reachable. Treat the artifact
as review evidence: give the user a stable URL or local entry point and capture their selection.
