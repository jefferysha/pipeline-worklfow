# React Patterns

Use explicit component props, typed state, accessible native controls where possible, and tests for
each interactive branch. Keep side effects isolated, render loading/error/empty states intentionally,
and avoid unchecked casts or untyped production escape hatches. Validate both state transitions and
user-visible output.
